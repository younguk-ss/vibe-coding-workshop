    05 · 고급 (선택)

    필요할 때만
    더합니다

    데이터를 저장해야 한다면

    Supabase

    • 학생 응답·점수·투표를 모아, 교사가 다른 기기에서 다시 볼 때
    • 퀴즈·시뮬레이션처럼 화면만으로 끝나면 DB 없이 충분
    • 코딩 에이전트에 Supabase(MCP)를 연결하면 표 만들기도 맡길 수 있다

    응답을 Supabase에 저장하고 교사 화면에서 다시 조회하게 해 줘. 연결 실패 안내, 데이터 접근 범위(RLS), 필요한 설정값과 배포 방법도 설명해 줘.

    브라우저에는 공개 키(publishable)만 넣습니다. 비밀 키(secret · service_role)는 넣지 않습니다. 학생 개인정보는 학교 방침에 따라 필요한 범위만 다룹니다.

    계속 고쳐 나가려면

    GitHub

    • 고칠 때마다 자동으로 다시 배포하고 싶을 때 (push → 자동 배포)
    • 변경 기록을 남기고, 이전 버전으로 돌아가고 싶을 때
    • 동료 교사와 코드를 공유하고 함께 고칠 때

    이 프로젝트를 GitHub 저장소에 올리고 Vercel 프로젝트와 연결해서, push할 때마다 자동 배포되게 해 줘. push 전에는 나에게 먼저 확인받아.

    오늘은 Drop으로 충분합니다. 같은 앱을 여러 번 고칠 때 도입합니다.
