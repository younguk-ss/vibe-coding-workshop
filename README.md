# 바이브 코딩 워크숍

정적 웹사이트(HTML/CSS/JS)입니다. 빌드 과정 없이 그대로 배포됩니다.

## 자동 배포

이 저장소는 Vercel 프로젝트 `vibe-dogu`와 연결되어 있습니다.

- `main` 브랜치에 커밋(푸시)하면 → **프로덕션 사이트에 자동 배포**
- 다른 브랜치나 Pull Request → **미리보기(Preview) 주소**가 따로 생성

### GitHub에서 바로 수정하기

1. 저장소에서 수정할 파일(예: `index.html`)을 엽니다.
2. 연필 아이콘(✏️ Edit)을 누르고 내용을 고칩니다.
3. **Commit changes**를 누르면 1분 안에 사이트에 반영됩니다.

### 내 컴퓨터에서 수정하기

```bash
git add -A
git commit -m "수정 내용"
git push
```
